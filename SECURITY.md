# Política de Seguridad

## Reporte de Vulnerabilidades

Valoramos la seguridad de nuestro proyecto. Si encuentras alguna vulnerabilidad, te pedimos que la reportes de manera responsable.

### Cómo reportar una vulnerabilidad

Por favor, no abras un issue público para reportar una vulnerabilidad. En su lugar, envía un correo electrónico detallando el hallazgo a: [correo-de-seguridad@ejemplo.com]

Por favor incluye:
- Una descripción detallada de la vulnerabilidad.
- Pasos para reproducir el problema.
- Cualquier posible mitigación que sugieras.

### Proceso de Respuesta

Una vez recibido el reporte:
1. Confirmaremos la recepción en un plazo de [X] días hábiles.
2. Analizaremos el impacto y la severidad.
3. Trabajaremos en una solución y te mantendremos informado.
4. Una vez resuelto, se publicará un aviso o se actualizará el código.

Gracias por ayudar a mantener este proyecto seguro.
